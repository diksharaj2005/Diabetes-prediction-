## Project Description

This project develops a binary classification system for predicting whether a patient is likely to have diabetes using clinical and demographic attributes. The project includes data analysis, preprocessing, multiple classification models, Multilayer Perceptron (MLP) development, model evaluation, and hyperparameter tuning.

## Dataset

The project uses the Pima Indians Diabetes Dataset.

**Target Variable:** `Outcome`

- `0` → Non-diabetic
- `1` → Diabetic

### Features

- Pregnancies
- Glucose
- Blood Pressure
- Skin Thickness
- Insulin
- BMI
- Diabetes Pedigree Function
- Age
